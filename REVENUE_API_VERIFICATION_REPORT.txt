7. ROOT CAUSE ANALYSIS: 404/405 ERRORS & VERCEL ROUTING
================================================================================
Why were 404 / 405 errors previously experienced?
1. Single Page Application (SPA) Hosting on Vercel:
   The domain https://sih-2026-revenue-dept.vercel.app is deployed as a static React SPA with outputDirectory: "frontend/dist".
   The vercel.json rewrites contain a catch-all rule:
     {"source": "/(.*)", "destination": "/index.html"}
   When an API request (such as POST /api/v1/auth/login) was sent to the relative path /api/v1/... on sih-2026-revenue-dept.vercel.app, Vercel attempted to serve the static index.html file.
   - For GET requests: Vercel served index.html (HTTP 200 with text/html), causing JSON parsers in the browser to throw SyntaxError: Unexpected token '<'.
   - For POST / PUT / DELETE requests: Vercel rejected HTTP POST requests aimed at static files with HTTP 405 Method Not Allowed.

2. Backend Deployment on Render:
   The FastAPI Python application is hosted as an independent web service on Render at:
     https://sih-2026-revenue-dept.onrender.com

3. Prevention & Resolution Established:
   - In frontend/src/services/api.ts:
     const PRODUCTION_BACKEND_URL = 'https://sih-2026-revenue-dept.onrender.com';
     const RAW_API_URL = import.meta.env.VITE_API_URL || import.meta.env.VITE_API_BASE_URL || (import.meta.env.PROD ? PRODUCTION_BACKEND_URL : '');
     const API_BASE_URL = cleanBaseUrl(RAW_API_URL);
   - All production frontend builds automatically bind to the Render backend host, ensuring zero 405/404 collision with Vercel SPA routing.

   - READ_ONLY_AUDITOR:

   - DPDP Consent Prerequisite: Consent must evaluate to VALID across 8 rules.
   - Address Data Completeness: All mandatory components and valid 6-digit PIN code required.
   - Proof Document Verification: OCR 6-part address match or authorized manual override required.
   - Approval Preconditions: Consent = VALID, Data = VALID, Document = MATCH / VALIDATED.
   - Mandatory Rejection Reason: Rejections without statutory reasons return HTTP 422.
   - Immutability: Once finalized (VERIFIED or REJECTED), applications cannot be modified or re-approved.
